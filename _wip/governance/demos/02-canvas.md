# Demo 2: Canvas

Which controls apply, and which were violated. Follows Slide 06. About 3 minutes.
Speech: `SPEAKER-NOTES.md`, Slide 06, beats D2.1 to D2.3.

## Start state

Console tab open. Click **Canvas** in the left nav and collapse **Verify**.

## Questions

Canvas offers these starter questions:

- Which controls apply to the Loan Origination Assistant?
- Did the latest evaluation runs pass?
- Which models are we paying for?
- What does Article 14 of the EU AI Act say?

The demo asks the first one, then types this follow-up:

> Which of those controls have been violated, and when?

The follow-up is not a starter question. Ask it once before the session, check that the
answer names at least one violation, and keep the wording that worked. The ledger runs from
2 June to 30 September, so don't add "this week" or "today."

## Click sheet

| Beat | Where | Do | Expect |
|---|---|---|---|
| D2.1 | Console tab | Switch to the tab. Click **Canvas** | Canvas with starter questions |
| D2.2 | Canvas | Click "Which controls apply to the Loan Origination Assistant?". Wait for the answer. Type the follow-up | Answer streams, then the follow-up answer |
| D2.3 | Canvas | Point at a violation in the answer | A violation with control, environment, and date |
| | Deck tab | Switch back. Continue to Slide 07 | |

A live violation on screen is the point of this demo. If the answer shows none, ask the
follow-up once more; don't move on without one.

## End state

Console tab left on Canvas.

## Fallback

If Canvas hangs for more than five seconds, switch back to the deck and read the Fallback
paragraph under Slide 06 in `SPEAKER-NOTES.md`.

## Reset

Canvas keeps a session list. Nothing to reset between takes.
